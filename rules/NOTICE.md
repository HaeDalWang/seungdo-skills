# 출처

`common/simplicity.md`는 [ponytail](https://github.com/DietrichGebert/ponytail) 4.10.0의
`skills/ponytail/SKILL.md`에서 가져와 수정한 것이다. 원본은 MIT이며, 이 파일도 MIT로 유지한다.

| 변경 | 내용 |
|---|---|
| 제거 | Persistence·Intensity(lite/ultra)·Boundaries — 모드 전환 장치. full 하나만 씀 |
| 제거 | 하드웨어 보정 문단(PCA9685) — 작업 영역 밖 |
| 이동 | "ONE runnable check" 규칙 → `common/testing.md` |
| 추가 | 적용 범위에 IaC·스크립트 명시, 사다리 4단에 인프라 예시(S3 lifecycle, chart value) |
| 수정 | 금지문 일부를 해야 할 행동으로 바꿈, Output에 CLAUDE.md 확신도 표기 유지 조항 |

`ponytail:` 주석 태그는 기존 코드의 주석과 호환되도록 그대로 쓴다.
